📝 ToDo List

A simple and functional ToDo List application developed using Python.

🚀 Features

Add Task

Show All Tasks

Search Task

Update Task

Delete Task

Complete Task

Show Completed Tasks

Show Pending Tasks

Queue Management

Save and Load Tasks using JSON

🛠️ Technologies Used

Python

Linked List

Queue

Deque

⚙️ How to Run

Clone the repository:

git clone https://github.com/DarthDream/ToDo.git

Open the project folder:

cd ToDo

Run the application:

python main.py

💡 Project Description

This project uses Linked List to manage tasks and Queue (FIFO) to organize pending tasks.

JSON is used to save and load task data, so tasks remain available after restarting the application.
